⏱ # How to display countdown (Start Countdown):

Linux PowerShell Node.js
Linux (Netcat / nc): Linux (Netcat) 
printf "COUNTDOWN:15\n" | nc 172.1.1.5 5000
Linux (Native Bash /dev/tcp): Bash 
echo -e "COUNTDOWN:15\n" > /dev/tcp/172.1.1.5/5000
Windows PowerShell: PowerShell 
powershell -Command "$c = New-Object System.Net.Sockets.TcpClient('172.1.1.5', 5000); $w = New-Object System.IO.StreamWriter($c.GetStream()); $w.WriteLine('COUNTDOWN:15'); $w.Flush(); $c.Close()"
Node.js: Node.js 
node -e "const s = require('net').connect(5000, '172.1.1.5', () => { s.write('COUNTDOWN:15\n'); }); s.on('data', d => { console.log(d.toString().trim()); s.destroy(); });"

📡 # Query Device Status:

Linux PowerShell Node.js
⚡ Example Expected Response:
STATE:COUNTDOWN,SEC:12 | STATE:IDLE | STATE:TEXT,MSG:GO
Linux (Netcat / nc with 1s read timeout): Linux (Netcat) 
printf "STATUS\n" | nc -w 1 172.1.1.5 5000
Windows PowerShell: PowerShell 
powershell -Command "$c = New-Object System.Net.Sockets.TcpClient('172.1.1.5', 5000); $w = New-Object System.IO.StreamWriter($c.GetStream()); $w.WriteLine('STATUS'); $w.Flush(); $r = New-Object System.IO.StreamReader($c.GetStream()); Write-Host $r.ReadLine(); $c.Close()"
Node.js: Node.js 
node -e "const s = require('net').connect(5000, '172.1.1.5', () => { s.write('STATUS\n'); }); s.on('data', d => { console.log(d.toString().trim()); s.destroy(); });"

🛠 # How to customize (Network Configuration):

Linux PowerShell Node.js

Configuration Instructions:

  • Target the device's current IP address (e.g. 172.1.1.6).
  • Update the JSON payload fields (ip, netmask, gateway, dns, port) with the desired new settings.
⚡ Immediate Response:
ACK: CONFIG_SAVED | IP: <new_ip> | Rebooting in 500ms
Linux (Netcat / nc): Linux (Netcat) 
printf 'CONFIG:{"ip":"172.1.1.5","netmask":"255.255.255.0","gateway":"172.1.1.1","dns":"8.8.8.8","port":5000}\n' | nc -w 1 172.1.1.6 5000
Windows PowerShell Network Reconfiguration: PowerShell 
powershell -NoProfile -Command "$cfg = @{ip='172.1.1.5'; netmask='255.255.255.0'; gateway='172.1.1.1'; dns='8.8.8.8'; port=5000} | ConvertTo-Json -Compress; $c = New-Object System.Net.Sockets.TcpClient('172.1.1.6', 5000); $w = New-Object System.IO.StreamWriter($c.GetStream()); $w.WriteLine('CONFIG:' + $cfg); $w.Flush(); $r = New-Object System.IO.StreamReader($c.GetStream()); Write-Host $r.ReadLine(); $c.Close()"
Node.js Network Reconfiguration: Node.js 
node -e "const s = require('net').connect(5000, '172.1.1.6', () => { s.write('CONFIG:' + JSON.stringify({ip:'172.1.1.5',netmask:'255.255.255.0',gateway:'172.1.1.1',dns:'8.8.8.8',port:5000}) + '\n'); }); s.on('data', d => { console.log(d.toString().trim()); s.destroy(); });"

🐧 # Linux / Unix Terminal Tips:

Linux Tips

Netcat Installation & Distribution Notes:

  • On Ubuntu / Debian: sudo apt install netcat-openbsd (standard nc).
  • On RedHat / CentOS / Fedora: sudo dnf install nmap-ncat.
  • On Arch Linux: sudo pacman -S openbsd-netcat.
  • Use printf instead of echo for exact newline (\n) line endings without escape variability.
  • Add -w 1 to automatically exit after 1 second if querying bidirectional responses like STATUS.
Action Linux Command (Netcat) Bash Native (/dev/tcp)
Start 15s Countdown printf "COUNTDOWN:15\n" | nc 172.1.1.5 5000 echo -e "COUNTDOWN:15\n" > /dev/tcp/172.1.1.5/5000
Pause Countdown printf "PAUSE\n" | nc 172.1.1.5 5000 echo -e "PAUSE\n" > /dev/tcp/172.1.1.5/5000
Resume Countdown printf "RESUME\n" | nc 172.1.1.5 5000 echo -e "RESUME\n" > /dev/tcp/172.1.1.5/5000
Stop / Abort printf "STOP\n" | nc 172.1.1.5 5000 echo -e "STOP\n" > /dev/tcp/172.1.1.5/5000
Display "GO" printf "TEXT:GO\n" | nc 172.1.1.5 5000 echo -e "TEXT:GO\n" > /dev/tcp/172.1.1.5/5000
Query Status printf "STATUS\n" | nc -w 1 172.1.1.5 5000 exec 3<>/dev/tcp/172.1.1.5/5000 && echo -e "STATUS\n" >&3 && head -n 1 <&3 && exec 3>&-
