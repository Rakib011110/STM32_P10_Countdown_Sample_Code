TCP Commands & Control Quick Reference

One-click copy terminal commands for PowerShell and Node.js to control your P10 Countdown Display over Ethernet.

⚙️ Target Settings:

⏱ # How to display countdown :

Using powershell: PowerShell 
powershell -Command "$c = New-Object System.Net.Sockets.TcpClient('172.1.1.5', 5000); $w = New-Object System.IO.StreamWriter($c.GetStream()); $w.WriteLine('COUNTDOWN:15'); $w.Flush(); $c.Close()"
Using node: Node.js 
node -e "const s = require('net').connect(5000, '172.1.1.5', () => { s.write('COUNTDOWN:15\n'); }); s.on('data', d => { console.log(d.toString().trim()); s.destroy(); });"

⏸ # Pause Countdown:

Node.js 
node -e "const s = require('net').connect(5000, '172.1.1.5', () => { s.write('PAUSE\n'); s.destroy(); });"

▶ # Resume Countdown:

Node.js 
node -e "const s = require('net').connect(5000, '172.1.1.5', () => { s.write('RESUME\n'); s.destroy(); });"

🔤 # Display Text (e.g. GO, STOP, RDY):

Node.js
Quick Word Presets: 
node -e "const s = require('net').connect(5000, '172.1.1.5', () => { s.write('TEXT:GO\n'); s.destroy(); });"

🛠 # How to customize:

PowerShell

Configuration Instructions:

  • Change the first IP address TcpClient('172.1.1.6', 5000) to the device's current IP.
  • Change ip='172.1.1.5', netmask='...', gateway='...' inside @{...} to the new settings you want to apply.
⚡ Immediate Response:
ACK: CONFIG_SAVED | IP: <new_ip> | Rebooting in 500ms
PowerShell Network Reconfiguration Command: 
powershell -NoProfile -Command "$cfg = @{ip='172.1.1.5'; netmask='255.255.255.0'; gateway='172.1.1.1'; dns='8.8.8.8'; port=5000} | ConvertTo-Json -Compress; $c = New-Object System.Net.Sockets.TcpClient('172.1.1.6', 5000); $w = New-Object System.IO.StreamWriter($c.GetStream()); $w.WriteLine('CONFIG:' + $cfg); $w.Flush(); $r = New-Object System.IO.StreamReader($c.GetStream()); Write-Host $r.ReadLine(); $c.Close()"
